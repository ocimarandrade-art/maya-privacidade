Política de Privacidade da Maya

Última atualização: novembro de 2026.

A Maya é um assistente pessoal de uso privado. Ela roda no computador do próprio usuário e só acessa as contas que o próprio usuário conectou e autorizou.

Quais dados são acessados

Com a autorização do usuário pelo Google, a Maya pode ler e criar eventos na Agenda do Google e ler e-mails, criar rascunhos e enviar e-mails pelo Gmail, sempre a pedido do próprio usuário.

Como os dados são usados

Os dados são usados apenas para ajudar o próprio usuário: mostrar a agenda, resumir e-mails importantes, preparar respostas e criar lembretes. Os dados não são vendidos, não são usados para publicidade e não são compartilhados com terceiros, exceto o processamento necessário pelo serviço de inteligência artificial usado para gerar respostas.

Onde os dados ficam

As informações ficam armazenadas no computador do usuário. O usuário pode desconectar a conta do Google a qualquer momento, pelo próprio aplicativo ou em myaccount.google.com/permissions, e apagar os dados locais.

Uso de dados do Google

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Contato

Dúvidas sobre esta política podem ser enviadas ao e-mail de suporte exibido na tela de autorização do Google.
